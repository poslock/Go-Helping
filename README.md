Go Helping – Community-Based Helping Platform

Go Helping is an Android-based social platform designed to connect people who need assistance with individuals who are willing to help. The application encourages kindness, collaboration, and community engagement through a Good Deeds (GD) reward system.

Users can register as Helpers or Needers, create and participate in helping activities, communicate through an integrated chat feature, and earn Good Deeds points by completing tasks. These points can then be used to request assistance from other members.

The application also includes task completion tracking, user profiles, and a two-sided rating system to promote trust, accountability, and positive interactions within the community.

Key Features:

User authentication and role-based access.

Helper and Needer user roles.

Good Deeds (GD) reward and balance system.

Helping task creation and management.

Real-time chat functionality.

Task completion tracking.

Two-sided user rating and review system.

User profile management.

Technology Stack:

Java

Android Studio

Firebase Authentication

Cloud Firestore

Project Objective:

To build a digital platform that makes helping others more accessible, encourages social responsibility, and creates a community where people can support one another.
